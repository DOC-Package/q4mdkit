# cif2crd.py - CIF to CHARMM CRD/PDB and CGenFF mol2 Converter

## Overview

Converts a CIF crystal structure file to CHARMM-compatible formats:
- **CRD**: CHARMM coordinate file (extended format) for entire supercell
- **PDB**: Visualization format for supercell (optional)
- **mol2**: SYBYL format for a single template molecule (for CGenFF parameterization)

All outputs have **consistent per-molecule atom ordering**, critical for CHARMM topology application.

## Key Features

- **Graph-based molecule detection**: Uses covalent bonding under periodic boundary conditions
- **Deterministic atom ordering**: Ensures all molecule copies have identical internal atom order
- **Graph isomorphism matching**: Maps each molecule to a template using RMSD-based disambiguation
- **Unwrapping**: Places each molecule in a single periodic image (no broken bonds)
- **Optional recentering/wrapping**: For compact visualization
- **SYBYL atom type inference**: Automatically assigns C.3, C.ar, N.2, etc. for mol2 output
- **Bond information**: mol2 includes connectivity for CGenFF parameterization

## Usage

```bash
python cif2crd.py --cif INPUT.cif --supercell NX NY NZ [options]
```

## Arguments

### Required Arguments

| Option | Description |
|--------|-------------|
| `--cif` | Input CIF file path |
| `--supercell NX NY NZ` | Supercell repeats in each direction (e.g., `3 3 3` for 27× unit cell) |

### Output File Arguments (all optional with auto-generated defaults)

| Option | Default | Description |
|--------|---------|-------------|
| `--crd` | `<cif_basename>.crd` | Output CRD file path (CHARMM format) |
| `--pdb` | `<cif_basename>.pdb` | Output PDB file path (supercell, for visualization) |
| `--mol2` | `<cif_basename>.mol2` | Output mol2 file path (single molecule, for CGenFF) |

### Optional Arguments

| Option | Default | Description |
|--------|---------|-------------|
| `--bond-scale` | `1.10` | Scale factor for covalent radii in neighbor detection |
| `--resname` | `MOL` | Residue name in CRD/PDB |
| `--mol-name` | `MOL` | Molecule name for mol2 |
| `--no-recenter` | Flag | Disable recentering (enabled by default) |
| `--no-wrap` | Flag | Disable wrapping (enabled by default) |

## Algorithm Overview

Same core algorithm as `cif2gro.py`:
1. Molecule detection via graph connectivity
2. Template generation with deterministic ordering
3. Isomorphism matching with RMSD disambiguation
4. Coordinate unwrapping/recentering/wrapping

Additional steps for CHARMM/CGenFF:
5. SYBYL atom type inference (C.3, C.ar, N.2, etc.)
6. Bond type determination (1=single, ar=aromatic)
7. mol2 format output with TRIPOS sections

## Examples

### Basic: 3×3×3 Supercell with All Outputs

```bash
python cif2crd.py --cif pentacene.cif --supercell 3 3 3
# Creates: pentacene.crd, pentacene.pdb, pentacene.mol2
```

## Output Formats

### CRD File (CHARMM Extended Format)

```
* Generated by cif2pdb.py
* Supercell with consistent per-molecule atom order
*
      1944  EXT
         1         1  MOL       C1              7.7840000000        9.4380000000        5.6780000000  SYS              1    0.00000
         2         1  MOL       C2              6.8000000000        9.4430000000        6.6970000000  SYS              1    0.00000
        37         2  MOL       C1              9.6000000000        4.9800000000       17.7500000000  SYS              2    0.00000
```

**Format specification:**
- Title lines start with `*`
- Atom count line: `N_ATOMS  EXT`
- Fixed-width columns (130 characters total):
  - Cols 1-10: Atom number (I10)
  - Cols 11-20: Residue number (I10)
  - Cols 21-30: Residue name (2 spaces + 8-char name)
  - Cols 31-40: Atom name (2 spaces + 8-char name)
  - Cols 41-60: X coordinate (F20.10)
  - Cols 61-80: Y coordinate (F20.10)
  - Cols 81-100: Z coordinate (F20.10)
  - Cols 101-110: Segment ID (2 spaces + 8-char ID, default "SYS")
  - Cols 111-120: Residue ID (I10)
  - Cols 121-130: Weighting (F10.5, default 0.0)

### PDB File (Supercell)

```
TITLE     Generated by cif2pdb.py
REMARK    Supercell with consistent per-molecule atom order
CRYST1   30.123   45.678   67.890  90.00  95.23  90.00 P 1           1
ATOM      1  C1  MOL A   1       7.784   9.438   5.678  1.00  0.00           C  
ATOM      2  C2  MOL A   1       6.800   9.443   6.697  1.00  0.00           C  
TER
ATOM     37  C1  MOL A   2       9.600   4.980  17.750  1.00  0.00           C  
TER
END
```

**Features:**
- CRYST1 record with unit cell parameters
- TER records separate molecules
- Chain ID = A, residue ID = molecule number
- Numbered atom names (C1, C2, H6, etc.)

### mol2 File (Single Molecule for CGenFF)

```
@<TRIPOS>MOLECULE
MOL
 36 40 1 0 0
SMALL
USER_CHARGES


@<TRIPOS>ATOM
      1 C1          7.7840    9.4380    5.6780 C.ar        1 MOL         0.0000
      2 C2          6.8000    9.4430    6.6970 C.ar        1 MOL         0.0000
      6 H6          5.9850    9.9100    6.5520 H           1 MOL         0.0000
@<TRIPOS>BOND
     1    1    2     ar
     2    1    3     ar
     6    2    6     1
@<TRIPOS>SUBSTRUCTURE
     1 MOL             1 TEMP              0 ****  ****    0 ROOT
```

**Features:**
- SYBYL atom types (C.3, C.ar, N.2, O.2, etc.)
- Bond connectivity with types (1=single, ar=aromatic)
- Compatible with CGenFF server and other force field tools

## Internal Functions

### `write_pdb_supercell(path, atoms, molecule_chunks, per_mol_orders, unwrapped_positions, resname="MOL")`

Writes PDB file for the entire supercell with consistent atom ordering.

**Parameters:**
- `path`: Output PDB file path (str)
- `atoms`: Original ASE Atoms object (for atomic numbers and cell)
- `molecule_chunks`: List of atom index lists for each molecule (List[List[int]])
- `per_mol_orders`: Reordering map for each molecule (Dict[int, List[int]])
- `unwrapped_positions`: Unwrapped positions for each molecule in Å (List[np.ndarray])
- `resname`: Residue name (str, default "MOL")

**Output features:**
- CRYST1 record with cell parameters (a, b, c, α, β, γ)
- TER records between molecules
- Chain ID = A for all molecules
- Residue ID = molecule index + 1
- Numbered atom names (C1, C2, H6, etc.)

### `write_crd_supercell(path, atoms, molecule_chunks, per_mol_orders, unwrapped_positions, resname="MOL")`

Writes CHARMM CRD file (extended format) for the entire supercell.

**Parameters:**
- Same as `write_pdb_supercell()`

**CHARMM CRD extended format:**
- Fixed-width format (130 characters per line)
- Title lines start with `*`
- Atom count line: `N_ATOMS  EXT`
- Each atom line has 10 fields with precise column positions
- Segment ID = "SYS", weighting = 0.0

**Column specification:**
```
Cols   1-10: Atom number (I10)
Cols  11-20: Residue number (I10)
Cols  21-30: Residue name (2 spaces + 8 chars)
Cols  31-40: Atom name (2 spaces + 8 chars)
Cols  41-60: X coordinate (F20.10, Å)
Cols  61-80: Y coordinate (F20.10, Å)
Cols  81-100: Z coordinate (F20.10, Å)
Cols 101-110: Segment ID (2 spaces + 8 chars)
Cols 111-120: Residue ID (I10)
Cols 121-130: Weighting (F10.5)
```

### `infer_sybyl_atom_type(element, degree, num_h_neighbors) -> str`

Infers SYBYL atom type from element and connectivity.

**Parameters:**
- `element`: Element symbol (str, e.g., 'C', 'H', 'N', 'O')
- `degree`: Number of bonded neighbors (int)
- `num_h_neighbors`: Number of hydrogen neighbors (int)

**Returns:**
- SYBYL atom type (str)

**Inference rules:**

| Element | Degree | Type | Description |
|---------|--------|------|-------------|
| C | 4 | C.3 | sp³ carbon (tetrahedral) |
| C | 3 | C.ar | Aromatic carbon |
| C | 2 | C.2 | sp² carbon (double bond) |
| C | 1 | C.1 | sp carbon (triple bond) |
| H | any | H | Hydrogen |
| N | 3 | N.3 | sp³ nitrogen |
| N | 2 | N.2 | sp² nitrogen |
| N | 1 | N.1 | sp nitrogen |
| O | 2 | O.3 | sp³ oxygen (ether, alcohol) |
| O | 1 | O.2 | sp² oxygen (carbonyl) |
| S | 2 | S.3 | sp³ sulfur |
| S | 1 | S.2 | sp² sulfur |
| P | any | P.3 | Phosphorus |
| F, Cl, Br, I | any | Element | Halogens |

**Note:** Assumes degree 3 carbons are aromatic. For more accurate typing, use specialized tools.

### `write_mol2_single_molecule(path, atoms, mol_indices, ordered_indices, unwrapped_pos, bond_scale=1.10, mol_name="MOL")`

Writes SYBYL-compliant mol2 file for a single molecule with bond information.

**Parameters:**
- `path`: Output mol2 file path (str)
- `atoms`: Original ASE Atoms object
- `mol_indices`: Global indices of atoms in this molecule (List[int])
- `ordered_indices`: Local indices defining the canonical order (List[int])
- `unwrapped_pos`: Unwrapped positions for this molecule in Å (np.ndarray)
- `bond_scale`: Scale factor for covalent radii (float, default 1.10)
- `mol_name`: Molecule name (str, default "MOL")

**Output sections:**
1. **@<TRIPOS>MOLECULE**: Molecule name, counts, charge type
2. **@<TRIPOS>ATOM**: Atom lines with SYBYL types
   - Format: `atom_id atom_name x y z atom_type subst_id subst_name charge`
3. **@<TRIPOS>BOND**: Bond connectivity
   - Format: `bond_id atom1 atom2 bond_type`
   - Bond types: `1` (single), `ar` (aromatic)
4. **@<TRIPOS>SUBSTRUCTURE**: Substructure definition

**Bond type determination:**
- `ar` (aromatic): Both atoms are C.ar (aromatic carbon)
- `1` (single): All other cases

**Note:** Does not detect double/triple bonds automatically. For accurate typing, use RDKit or specialized chemistry tools.

## Workflow Integration

### Typical CHARMM/CGenFF Pipeline

1. **Get CIF structure** (experimental or optimized)

2. **Add hydrogens** (if missing):
   ```bash
   obabel pentacene.cif -O pentacene_H.cif -h
   ```

3. **Generate supercell CRD/mol2**:
   ```bash
   python cif2crd.py --cif pentacene_H.cif --supercell 3 3 3
   # Creates: pentacene_H.crd, pentacene_H.pdb, pentacene_H.mol2
   ```

4. **Parameterize with CGenFF**:
   - Submit `pentacene_H.mol2` to CGenFF server (https://cgenff.umaryland.edu/)
   - Download `pentacene.str` (CHARMM stream file with RTF and parameters)

5. **Generate PSF topology**:
   ```bash
   python build_psf_pdb.py \
       --pdb pentacene_H.pdb \
       --crd pentacene_H.crd \
       --toppar pentacene.str \
       --nmol 54 \
       --psf system.psf
   ```

6. **Run CHARMM/NAMD simulations** with `system.psf` and `pentacene_H.crd`

## Python API

```python
from ase.io import read
from mol_utils import split_molecules_pbc, unwrap_to_single_image, deterministic_template_order
from cif2crd import write_mol2_single_molecule, write_crd_supercell

# Load structure
atoms = read("pentacene.cif")

# Detect molecules
molecules = split_molecules_pbc(atoms, scale=1.10)

# Unwrap first molecule
unwrapped_pos = unwrap_to_single_image(atoms, molecules[0])

# Write mol2 for CGenFF
from cif2crd import build_graph
mol0 = Atoms(numbers=atoms.numbers[molecules[0]], positions=unwrapped_pos)
G0 = build_graph(mol0)
template_order = deterministic_template_order(G0, mol0, list(range(len(molecules[0]))))

write_mol2_single_molecule(
    "template.mol2",
    atoms,
    molecules[0],
    template_order,
    unwrapped_pos,
    mol_name="PENTACENE"
)
```

## Troubleshooting

### "Detected a single connected component"
- Same as cif2gro.py - may not be a molecular crystal
- Try adjusting `--bond-scale`

### CGenFF errors with mol2 file
- Ensure hydrogens are present
- Check SYBYL atom types are reasonable
- For complex molecules, manually edit mol2 or use RDKit for typing

### CRD format issues with CHARMM
- Ensure exact column widths (130 characters per line)
- Check segment ID is 8 characters or less
- Verify extended format flag `EXT` is present

## Notes

- **Atom ordering consistency** is critical for topology application
- **SYBYL atom type inference** is heuristic; for publication-quality work, verify types
- **CGenFF** is recommended for organic molecules; inorganic/metal systems need custom parameters
- **Impropers** in CHARMM CGenFF are typically zero for aromatic hydrocarbons (expected behavior)
