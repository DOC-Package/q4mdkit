# build_psf.py - CHARMM PSF Topology Generator

## Overview

Generates CHARMM PSF (Protein Structure File) topology for molecular crystal systems using pyCHARMM. The PSF file contains connectivity information (bonds, angles, dihedrals) required for CHARMM simulations.

## Key Features

- **Dual-file input**: Uses PDB for sequence/topology and CRD for precise coordinates
- **Automatic connectivity**: Generates bonds, angles, dihedrals, and impropers
- **CGenFF integration**: Reads topology/parameters from CGenFF stream files
- **pyCHARMM-based**: No external CHARMM executable required
- **Crystal-aware**: Handles multiple identical molecules with proper segmentation

## Usage

```bash
python build_psf.py --pdb INPUT.pdb --crd INPUT.crd --toppar TOPPAR.str --nmol N [options]
```

## Arguments

### Required Arguments

| Option | Description |
|--------|-------------|
| `--pdb` | Input PDB file (defines atom names and residue structure) |
| `--crd` | Input CRD file (provides high-precision coordinates) |
| `--toppar` | CHARMM topology/parameter stream file (from CGenFF) |
| `--nmol` | Number of molecules in the crystal |

### Optional Arguments

| Option | Default | Description |
|--------|---------|-------------|
| `--resname` | `MOL` | Residue name for molecules |
| `--segid` | `SYS` | Segment ID for the system |
| `--psf` | `system.psf` | Output PSF file path |
| `--out-pdb` | None | Optional output PDB file path |

## Workflow

The script follows the standard CHARMM topology generation workflow:

1. **Read topology/parameters**: Load base CHARMM36 CGenFF force field
2. **Read molecule parameters**: Stream molecule-specific topology/parameters from CGenFF
3. **Define sequence**: Create sequence of `nmol` copies of `resname`
4. **Generate PSF**: Build connectivity (bonds, angles, dihedrals, impropers)
5. **Read coordinates**: Load high-precision coordinates from CRD file
6. **Write output**: Save PSF (and optionally PDB)

## Prerequisites

### 1. PDB File
- Single molecule template with correct atom names
- All atoms labeled with same residue name
- Generated by `cif2crd.py` or similar tool

### 2. CRD File
- Extended CHARMM coordinate format
- All molecules in crystal with consistent atom ordering
- Generated by `cif2crd.py` with `--supercell` option

### 3. CGenFF Stream File
- Contains molecule-specific topology and parameters
- Obtained from https://cgenff.umaryland.edu/
- Upload mol2 file → download `.str` file

### 4. Base Force Field (Optional)
- CHARMM36 CGenFF base files (auto-detected if available):
  - `top_all36_cgenff.rtf`
  - `par_all36_cgenff.prm`
- Script will create minimal parameters if not found

## Examples

### Basic: Generate PSF for Pentacene Crystal

```bash
python build_psf.py \
    --pdb pentacene.pdb \
    --crd pentacene_333.crd \
    --toppar pentacene.str \
    --nmol 27 \
    --psf pentacene.psf
```

### With All Options

```bash
python build_psf.py \
    --pdb rubrene.pdb \
    --crd rubrene_222.crd \
    --toppar rubrene.str \
    --resname RUB \
    --nmol 8 \
    --segid CRY \
    --psf rubrene.psf \
    --out-pdb rubrene_final.pdb
```

### Calculate Number of Molecules

For a supercell with dimensions `nx × ny × nz` and `n_per_cell` molecules per unit cell:
```python
nmol = nx * ny * nz * n_per_cell
```

Example: 3×3×3 supercell with 1 molecule per unit cell:
```bash
python build_psf.py ... --nmol 27  # 3 * 3 * 3 * 1
```

## Output Files

### PSF File (`.psf`)
CHARMM PSF format containing:
- **Atoms**: Atom types, charges, masses
- **Bonds**: Connectivity between atoms
- **Angles**: Three-atom angle definitions
- **Dihedrals**: Four-atom torsion definitions
- **Impropers**: Out-of-plane improper dihedrals

Format excerpt:
```
       1 !NTITLE
 REMARKS PSF for molecular crystal

    2160 !NATOM
       1 SYS  1    MOL  C1   CG2R61 -0.115000       12.0110           0
       2 SYS  1    MOL  C2   CG2R61 -0.115000       12.0110           0
       ...

    2304 !NBOND: bonds
       1       2       1       6       1      10       2       3
       ...
```

### PDB File (optional, `--out-pdb`)
Standard PDB format with:
- Coordinates from CRD file
- Connectivity from PSF
- Useful for visualization and validation

## Validation

After generating PSF:

### 1. Check Atom Count
```bash
grep "!NATOM" system.psf
# Should match: atoms_per_molecule × nmol
```

### 2. Check Bond Count
```bash
grep "!NBOND" system.psf
# Should be reasonable (typically ~1.5 × atom count for organic molecules)
```

### 3. Visualize Structure
```bash
# With VMD
vmd system.psf rubrene_222.crd

# Check for:
# - Correct connectivity
# - No broken bonds
# - Proper molecular structure
```

### 4. Check Energies
```python
import pycharmm
import pycharmm.read as read

read.psf_card("system.psf")
read.crd("system.crd")

# Check for reasonable initial energy
# Large positive values suggest problems
```

## Troubleshooting

### Issue: "Mass not found for atom type"

**Cause**: Missing base CHARMM36 CGenFF files

**Solution 1**: Install base force field files
```bash
# Download from MacKerell group or CHARMM website
# Place in: /home/takahashi/charmm/charmm/toppar/
```

**Solution 2**: Script will attempt to create minimal parameters

### Issue: "Residue MOL not found in topology"

**Cause**: Stream file doesn't define the residue

**Solution**: Ensure CGenFF stream file is correct
```bash
# Check stream file contains:
grep "RESI MOL" pentacene.str
```

### Issue: "Atom count mismatch"

**Cause**: `nmol` doesn't match actual molecules in CRD

**Solution**: Count atoms in CRD and calculate:
```bash
# Atoms in CRD / atoms per molecule = nmol
wc -l pentacene.crd
# Example: 972 atoms / 36 atoms/mol = 27 molecules
```

### Issue: "Coordinates not read correctly"

**Cause**: CRD file format issues

**Solution**: Ensure CRD is extended format (not card format)
```bash
# Extended format has more precise coordinates:
# X: columns 21-40 (20 chars, F20.10)
# Y: columns 41-60 (20 chars, F20.10)
# Z: columns 61-80 (20 chars, F20.10)
```

## Integration with cif2crd.py

Complete workflow from CIF to PSF:

```bash
# 1. Convert CIF to CHARMM formats
python src/engines/pycharmm/cif2crd.py \
    --cif pentacene.cif \
    --supercell 3 3 3 \
    --crd pentacene.crd \
    --pdb pentacene.pdb \
    --mol2 pentacene.mol2

# 2. Generate CGenFF parameters (external)
# Upload pentacene.mol2 to https://cgenff.umaryland.edu/
# Download pentacene.str

# 3. Build PSF
python src/engines/pycharmm/build_psf.py \
    --pdb pentacene.pdb \
    --crd pentacene.crd \
    --toppar pentacene.str \
    --nmol 27 \
    --psf system.psf

# 4. Run simulation (CHARMM or pyCHARMM)
```

## Technical Notes

### Why Two Input Files?

- **PDB**: Human-readable, defines atom names and residue structure
- **CRD**: High-precision coordinates (20.10 format vs PDB's 8.3)
- PSF generation needs topology info (from PDB) and precise coords (from CRD)

### Sequence Definition

The script generates a sequence of `nmol` identical residues:
```
read sequence card
* Molecular crystal sequence
*
27
MOL MOL MOL MOL MOL MOL MOL MOL MOL MOL
MOL MOL MOL MOL MOL MOL MOL MOL MOL MOL
MOL MOL MOL MOL MOL MOL MOL
```

### Autogenerate Command

After PSF generation, the script runs:
```
autogenerate angles dihedrals impropers
```
This creates angle, dihedral, and improper definitions based on:
- Atom types in topology
- Connectivity in PSF
- Parameter definitions in force field

### Extended I/O Format

The script sets:
```
IOFORMAT EXTENDED
```
This enables:
- 10-digit atom IDs (vs 5 in card format)
- 8-character residue names
- High-precision coordinates
- Required for large systems (>99,999 atoms)
