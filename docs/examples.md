# Usage Examples

Complete workflows for preparing and running molecular crystal simulations with GROMACS and CHARMM.

---

## Example 1: GROMACS Simulation of Pentacene Crystal

### Prerequisites
- Input: `pentacene.cif` (crystallographic information file)
- LigParGen account (https://traken.chem.yale.edu/ligpargen/)
- GROMACS installed

### Step 1: Convert CIF to GRO

```bash
# Create a 3×3×3 supercell and export template molecule
python src/engines/openmm/cif2gro.py \
    --cif pentacene.cif \
    --super 3 3 3 \
    --out pentacene_333.gro \
    --template-pdb pentacene_template.pdb \
    --resname PEN
```

**Output:**
- `pentacene_333.gro`: GROMACS coordinate file with 27 molecules (3³ × 1 molecule/cell)
- `pentacene_template.pdb`: Single molecule for parameterization

**Verification:**
```bash
# Check atom count (should be 27 × 36 = 972 for pentacene)
grep "Generated by" pentacene_333.gro

# Visualize
vmd pentacene_333.gro  # or pymol, etc.
```

### Step 2: Generate Force Field Parameters

**Option A: LigParGen (OPLS-AA)**

1. Visit https://traken.chem.yale.edu/ligpargen/
2. Upload `pentacene_template.pdb`
3. Charge model: 1.14*CM1A-LBCC
4. Download `pentacene.itp` (GROMACS ITP format)

**Option B: ATB (Automated Topology Builder)**

1. Visit https://atb.uq.edu.au/
2. Upload `pentacene_template.pdb`
3. Download GROMACS topology

### Step 3: Create GROMACS Topology

```bash
python src/engines/openmm/build_top.py pentacene_333.gro \
    --itp pentacene.itp \
    --ff oplsaa.ff/forcefield.itp \
    --atoms-per-mol 36 \
    --mol-name PEN \
    --system-name "Pentacene Crystal 3x3x3" \
    -o topol.top
```

**Output:** `topol.top`
```
; Topology file for Pentacene Crystal 3x3x3

#include "oplsaa.ff/forcefield.itp"
#include "pentacene.itp"

[ system ]
Pentacene Crystal 3x3x3

[ molecules ]
PEN        27
```

### Step 4: Energy Minimization

Create `em.mdp`:
```
; Energy minimization
integrator  = steep
nsteps      = 5000
emtol       = 1000.0
emstep      = 0.01
```

Run:
```bash
gmx grompp -f em.mdp -c pentacene_333.gro -p topol.top -o em.tpr
gmx mdrun -deffnm em
```

### Step 5: NVT Equilibration

Create `nvt.mdp`:
```
; NVT equilibration
integrator  = md
dt          = 0.001         ; 1 fs
nsteps      = 50000         ; 50 ps
tcoupl      = v-rescale
tc-grps     = System
tau_t       = 0.1
ref_t       = 300
```

Run:
```bash
gmx grompp -f nvt.mdp -c em.gro -p topol.top -o nvt.tpr
gmx mdrun -deffnm nvt
```

### Step 6: NPT Production

Create `npt.mdp`:
```
; NPT production
integrator  = md
dt          = 0.002         ; 2 fs
nsteps      = 5000000       ; 10 ns

tcoupl      = nose-hoover
tc-grps     = System
tau_t       = 1.0
ref_t       = 300

pcoupl      = parrinello-rahman
pcoupltype  = isotropic
tau_p       = 5.0
ref_p       = 1.0
compressibility = 4.5e-5
```

Run:
```bash
gmx grompp -f npt.mdp -c nvt.gro -p topol.top -o npt.tpr
gmx mdrun -deffnm npt
```

### Step 7: Analysis

```bash
# Extract trajectory
gmx trjconv -s npt.tpr -f npt.xtc -o npt_whole.xtc -pbc whole

# Density
echo "System" | gmx density -f npt.xtc -s npt.tpr -o density.xvg

# RDF
echo "System System" | gmx rdf -f npt.xtc -s npt.tpr -o rdf.xvg

# RMSD
echo "Backbone Backbone" | gmx rms -s npt.tpr -f npt.xtc -o rmsd.xvg
```

## Example 2: CHARMM Simulation of Rubrene Crystal

### Prerequisites
- Input: `rubrene.cif`
- CGenFF account (https://cgenff.umaryland.edu/)
- CHARMM or pyCHARMM installed

### Step 1: Convert CIF to CHARMM Formats

```bash
# Create 2×2×2 supercell, generate all CHARMM files
python src/engines/pycharmm/cif2crd.py \
    --cif rubrene.cif \
    --supercell 2 2 2 \
    --crd rubrene_222.crd \
    --pdb rubrene_222.pdb \
    --mol2 rubrene.mol2 \
    --resname RUB \
    --mol-name RUB
```

**Output:**
- `rubrene_222.crd`: CHARMM coordinate file (8 molecules)
- `rubrene_222.pdb`: PDB for visualization
- `rubrene.mol2`: mol2 with SYBYL atom types for CGenFF

### Step 2: Generate CGenFF Parameters

1. Visit https://cgenff.umaryland.edu/
2. Upload `rubrene.mol2`
3. Download:
   - `rubrene.str`: CHARMM stream file with parameters
   - `rubrene.prm`: CHARMM parameter file

### Step 3: Create PSF Topology

```bash
python src/engines/pycharmm/build_psf.py rubrene_222.crd \
    --str rubrene.str \
    --atoms-per-mol 70 \
    --mol-name RUB \
    -o rubrene.psf
```

### Step 4: Run pyCHARMM Simulation

Create `run_md.py`:
```python
import pycharmm
import pycharmm.read as read
import pycharmm.write as write
import pycharmm.settings as settings
import pycharmm.minimize as minimize
import pycharmm.dynamics as dyn

# Read topology and parameters
read.rtf("top_all36_cgenff.rtf")
read.prm("par_all36_cgenff.prm")
read.stream("rubrene.str")

# Read PSF and coordinates
read.psf_card("rubrene.psf")
read.crd("rubrene_222.crd")

# Energy minimization
minimize.run_sd(nstep=1000)
minimize.run_abnr(nstep=5000)

# Dynamics setup
dyn.set_fbeta(5.0)
dyn.set_timestep(0.001)  # 1 fs

# Heat to 300 K
dyn.run_dynamics(
    nstep=10000,
    firstt=0.0,
    finalt=300.0,
    tstruct=300.0,
)

# Production run
dyn.run_dynamics(
    nstep=1000000,  # 1 ns
    finalt=300.0,
    tstruct=300.0,
)

# Save
write.coor_card("final.crd")
write.coor_dcd("trajectory.dcd")
```

Run:
```bash
python run_md.py
```

## Example 3: Quick Validation Workflow

### Check Molecule Detection

```python
from ase.io import read
from src.common.mol_utils import split_molecules_pbc

# Load structure
atoms = read("pentacene.cif")

# Detect molecules
molecules = split_molecules_pbc(atoms, scale=1.10)

print(f"Unit cell contains {len(molecules)} molecules")
print(f"First molecule: {len(molecules[0])} atoms")
print(f"Atom indices: {molecules[0]}")
```

### Visualize Bond Graph

```python
import matplotlib.pyplot as plt
import networkx as nx
from ase.io import read
from src.common.mol_utils import build_graph

atoms = read("pentacene.cif")
G = build_graph(atoms, scale=1.10)

# Draw graph
pos = nx.spring_layout(G)
colors = [G.nodes[i]['Z'] for i in G.nodes]
nx.draw(G, pos, node_color=colors, with_labels=True, cmap='tab20')
plt.title("Covalent Bond Graph")
plt.show()
```

### Check Atom Ordering Consistency

```python
from ase.io import read

# Read GRO file
atoms = read("pentacene_333.gro")

# Extract first two molecules (36 atoms each)
mol1 = atoms[:36]
mol2 = atoms[36:72]

# Check element order
elements1 = mol1.get_chemical_symbols()
elements2 = mol2.get_chemical_symbols()

if elements1 == elements2:
    print("✓ Atom ordering is consistent")
else:
    print("✗ Atom ordering differs between molecules")
```

## Example 5: Troubleshooting

### Adjust Bond Detection Tolerance

If molecule detection fails (all atoms in one giant molecule or too many fragments):

```bash
# Increase tolerance for loose structures
python src/engines/openmm/cif2gro.py \
    --cif structure.cif \
    --out output.gro \
    --bond-scale 1.20  # default is 1.10

# Decrease for tight-packed structures
python src/engines/openmm/cif2gro.py \
    --cif structure.cif \
    --out output.gro \
    --bond-scale 1.05
```

### Disable Recentering/Wrapping

For structures that break when recentered:

```bash
python src/engines/openmm/cif2gro.py \
    --cif structure.cif \
    --out output.gro \
    --no-recenter \
    --no-wrap
```

### Debug Molecule Detection

```python
from ase.io import read
from src.common.mol_utils import split_molecules_pbc, build_graph

atoms = read("problem.cif")
G = build_graph(atoms, scale=1.10)

print(f"Total atoms: {len(atoms)}")
print(f"Graph nodes: {len(G.nodes)}")
print(f"Graph edges: {len(G.edges)}")
print(f"Connected components: {nx.number_connected_components(G)}")

# Check for isolated atoms
isolated = [n for n in G.nodes if G.degree[n] == 0]
print(f"Isolated atoms: {isolated}")
```
