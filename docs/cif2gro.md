# cif2gro.py - CIF to GROMACS GRO Converter with Consistent Atom Ordering

## Overview

Converts a CIF crystal structure file to GROMACS GRO format with **consistent per-molecule atom ordering**. This is critical for molecular dynamics simulations where each molecule instance must have identical atom ordering for proper topology application.

## Key Features

- **Graph-based molecule detection**: Uses covalent bonding under periodic boundary conditions
- **Deterministic atom ordering**: Ensures all molecule copies have identical internal atom order
- **Graph isomorphism matching**: Maps each molecule to a template using element, degree, and hydrogen neighbor matching
- **RMSD-based disambiguation**: When multiple isomorphisms exist (symmetric molecules), chooses the one with minimum RMSD after Kabsch alignment
- **Unwrapping**: Places each molecule in a single periodic image (no broken bonds across boundaries)
- **Optional recentering**: Creates compact clusters for better visualization
- **Template PDB export**: Generates single-molecule PDB for topology generation tools (LigParGen, CGenFF, etc.)

## Usage

```bash
python cif2gro.py --cif INPUT.cif --out OUTPUT.gro [options]
```

## Arguments

### Required Arguments

| Option | Description |
|--------|-------------|
| `--cif` | Input CIF file path |
| `--out` | Output GRO file path |

### Optional Arguments

| Option | Default | Description |
|--------|---------|-------------|
| `--super NX NY NZ` | `1 1 1` | Supercell repeats in each direction (e.g., `3 3 3` for 27x unit cell) |
| `--bond-scale` | `1.10` | Scale factor for covalent radii in neighbor detection (increase for loose structures) |
| `--resname` | `MOL` | Residue name to write in GRO file |
| `--template-pdb` | None | Also write one template molecule as PDB file (useful for topology generation) |
| `--no-recenter` | Flag | Disable recentering (enabled by default for compact visualization) |
| `--no-wrap` | Flag | Disable wrapping into box (enabled by default) |

## Algorithm Overview

### 1. Molecule Detection
- Build covalent bond graph under periodic boundary conditions
- Split into connected components (molecules)
- Sort molecules deterministically by fractional center-of-mass

### 2. Template Generation
- Select first molecule as template
- Create deterministic internal atom order using BFS from a unique starting node
- Starting node chosen by: element priority (heavy first), connectivity, position

### 3. Isomorphism Matching
- For each subsequent molecule:
  - Find graph isomorphism to template
  - Match by: element type, degree (number of bonds), hydrogen neighbor count
  - If multiple isomorphisms exist, choose one minimizing RMSD (Kabsch alignment)
  - Reorder atoms to match template order

### 4. Coordinate Processing
- Unwrap each molecule into single periodic image (removes bond breaks)
- Optional: Recenter system to origin for compact visualization
- Optional: Wrap molecules back into simulation box

### 5. Output
- Write GRO with consistent atom ordering across all molecules
- Optionally export template molecule as PDB

## Examples

### Basic: Single Unit Cell

```bash
python cif2gro.py --cif pentacene.cif --out pentacene.gro
```

### 3×3×3 Supercell with Template PDB

```bash
python cif2gro.py \
    --cif pentacene.cif \
    --super 3 3 3 \
    --out pentacene_333.gro \
    --template-pdb pentacene_template.pdb
```

### Without Recentering/Wrapping

```bash
# Disable default recentering and wrapping
python cif2gro.py \
    --cif rubrene.cif \
    --super 2 2 2 \
    --out rubrene_222.gro \
    --no-recenter \
    --no-wrap
```

### Custom Residue Name and Bond Tolerance

```bash
python cif2gro.py \
    --cif molecule.cif \
    --out system.gro \
    --resname RUB \
    --bond-scale 1.15 \
    --super 4 4 4
```

### GRO File Structure

```
Generated by cif2gro.py
 1944
    1MOL    C1    1   1.234   5.678   9.012
    1MOL    C2    2   1.345   5.789   9.123
    ...
    2MOL    C1   37   2.345   6.789   0.123
    2MOL    C2   38   2.456   6.890   0.234
    ...
   v1x      v2y      v3z      v1y      v1z      v2x      v2z      v3x      v3y
```

- Residue numbering: Sequential (1, 2, 3, ...)
- Atom names: `Element + position` (C1, C2, H1, H2, ...)
- All molecule instances have identical internal atom ordering

### Template PDB

Single molecule in vacuum with consistent atom ordering for topology generation:

```
ATOM      1  C1  MOL     1      12.340  56.780  90.120  1.00  0.00           C
ATOM      2  C2  MOL     1      13.450  57.890  91.230  1.00  0.00           C
...
```

## Important Notes

### Hydrogen Atoms
- **CIF files often lack hydrogen atoms**
- Add hydrogens before running (e.g., with OpenBabel):
  ```bash
  obabel input.cif -O output.cif -h
  ```

### Symmetric Molecules
- Highly symmetric molecules have multiple valid isomorphisms
- Script chooses the one minimizing RMSD (deterministic enough for MD)
- Different symmetry choices won't affect energy/dynamics

### Atom Ordering Importance
- Critical for GROMACS topology application
- All molecules must have identical atom order
- Template PDB should match GRO atom ordering

### Bond Detection
- Uses covalent radii scaled by `--bond-scale`
- Increase scale for loose/disordered structures
- Decrease if detecting spurious bonds

## Workflow Integration

### Typical MD Preparation Pipeline

1. **Get CIF structure** (experimental or optimized)
2. **Add hydrogens** (if missing):
   ```bash
   obabel pentacene.cif -O pentacene_H.cif -h
   ```
3. **Generate supercell GRO**:
   ```bash
   python cif2gro.py --cif pentacene_H.cif --super 3 3 3 \
       --out pentacene.gro --template-pdb pentacene_template.pdb
   ```
4. **Generate topology** (choose one):
   - **CHARMM/CGenFF**: Use `build_psf_pdb.py` with template PDB
   - **OPLS-AA/LigParGen**: Submit template PDB to LigParGen server
   - **GAFF/Antechamber**: Use Antechamber with template PDB
5. **Create GROMACS topology**:
   ```bash
   python build_top.py pentacene.gro --itp pentacene.itp --atoms-per-mol 36
   ```

## Internal Functions

### `gro_box_line(cell: np.ndarray) -> str`

Generates the GROMACS GRO triclinic box line (9-field format).

**Parameters:**
- `cell`: 3×3 ASE cell matrix (Å), rows are cell vectors

**Returns:**
- String with 9 fields: `v1x v2y v3z v1y v1z v2x v2z v3x v3y` (nm)

**Format:**
- Converts Å to nm (divide by 10)
- Order: `v1=a`, `v2=b`, `v3=c` (cell vectors)
- Fields: diagonal components first, then off-diagonal

### `write_template_pdb(path, symbols, positions, resname="MOL")`

Writes a single template molecule as PDB with numbered atom names.

**Parameters:**
- `path`: Output PDB file path (str)
- `symbols`: List of chemical symbols in template order (List[str])
- `positions`: Atomic positions in Ångström (np.ndarray, shape Nx3)
- `resname`: Residue name (str, default "MOL")

**Output format:**
```
REMARK   Template molecule with consistent atom ordering
ATOM      1 C1   MOL     1      12.340  56.780  90.120  1.00  0.00           C
ATOM      2 C2   MOL     1      13.450  57.890  91.230  1.00  0.00           C
ATOM      6 H6   MOL     1      14.560  58.900  92.340  1.00  0.00           H
END
```

**Features:**
- Numbered atom names (C1, C2, H6, etc.)
- Single residue (residue ID = 1)
- Compatible with LigParGen, CGenFF, and other topology generators

### `write_gro(path, atoms, molecule_chunks, per_mol_orders, positions, resid_name="MOL")`

Writes GROMACS GRO file with reordered molecules.

**Parameters:**
- `path`: Output GRO file path (str)
- `atoms`: Original ASE Atoms object (for symbols and cell)
- `molecule_chunks`: List of atom index lists for each molecule (List[List[int]])
- `per_mol_orders`: Reordering maps for each molecule (Dict[int, List[int]])
  - Keys: molecule index
  - Values: local index order (permutation of range(n_atoms))
- `positions`: List of position arrays for each molecule (List[np.ndarray])
  - Each array is unwrapped/recentered/wrapped positions in Å
- `resid_name`: Residue name (str, default "MOL")

**Output format:**
- Title line
- Total atom count
- Per-atom lines: `resid resname atomname atomid x y z` (nm)
- Triclinic box line (9 fields)

**Atom naming:**
- `Element + (local_position + 1)`: C1, C2, H6, etc.
- Ensures consistency with template PDB

## Python API

```python
# Custom script example
from ase.io import read
from mol_utils import split_molecules_pbc, unwrap_to_single_image
from cif2gro import write_template_pdb, write_gro

atoms = read("pentacene.cif")
molecules = split_molecules_pbc(atoms, scale=1.10)
print(f"Detected {len(molecules)} molecules")

# Unwrap first molecule
unwrapped_pos = unwrap_to_single_image(atoms, molecules[0])

# Write template PDB
symbols = [atoms.get_chemical_symbols()[i] for i in molecules[0]]
write_template_pdb("template.pdb", symbols, unwrapped_pos, resname="PEN")
```

## Troubleshooting

### "Detected a single connected component"
- Structure may not be a molecular crystal
- Try increasing `--bond-scale` if bonds are missing
- Check if CIF represents a single large polymer/network

### Inconsistent molecule sizes
- Some molecules have different atom counts
- Check for missing atoms in CIF
- Verify all molecules are complete

### Template PDB has broken bonds
- Use `--recenter` to unwrap molecules
- Template PDB uses unwrapped coordinates by default
